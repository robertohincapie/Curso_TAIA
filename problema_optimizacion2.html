Conjunto de tiempos o ranuras: T={1,2,…,k,…,K}\mathbf{T}=\{1, 2, \ldots, k, \ldots, K\}T={1,2,…,k,…,K}, indicando que tkt_ktk​ representa a una de las KKK ranuras.

Parámetros del problema:

Servicios de los usuarios:

El servicio del usuario iii está determinado por 3 cantidades

  • aia_iai​ La ranura de tiempo en que el servicio puede comenzar, no antes de ese tiempo.
  • bib_ibi​ La ranura de tiempo en que el servicio puede terminar como máximo. El usuario debe ser atendido entre aia_iai​ y bib_ibi​.
  • cic_ici​ La duración del servicio en tiempo dado por el número de ranuras necesarias.

Retrazos de movilidad:

Si un médico se tiene que desplazar desde un usuario i1i_1i1​ hasta la ubicación de un usuario i2i_2i2​, se toma un tiempo δi1,i2\delta_{i_1, i_2}δi1​,i2​​. Esta matriz está calculada para todos los pares posibles de usuarios y no es necesariamente simétrica. Esto aplica también para i1=Si_1=Si1​=S y para i2=Ti_2=Ti2​=T.

Costos de desplazamiento

Si un médico se tiene que desplazar desde un usuario i1i_1i1​ hasta la ubicación de un usuario i2i_2i2​, esto tiene un cost Ci1,i2C_{i_1, i_2}Ci1​,i2​​. Este costo aplica también para i1=Si_1=Si1​=S y para i2=Ti_2=Ti2​=T.

CmedC^{med}Cmed corresponde al costo de un médico por cumplir el turno.
